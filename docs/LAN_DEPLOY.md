# 把电脑当服务器：手机访问部署指南

> 目标：在**这台 Windows 电脑**上跑起正式服务，让同一个 Wi-Fi 下的手机、平板、另一台电脑都能用浏览器打开使用。
> 全程不需要 Docker、不需要云服务器、不需要域名。

本文所有命令都在项目根目录 `D:\project\2026-10-17-00-16-15` 下执行。

---

## 0. 先搞清楚三件事

| 概念 | 说明 |
|---|---|
| **占用的端口** | `3100`（可在 `PORT` 环境变量改） |
| **手机访问的地址** | `http://<电脑的局域网 IP>:3100`，例如 `http://192.168.1.6:3100` |
| **数据存在哪** | `.data/dev.db`（数据库）+ `.data/uploads/`（题目图片），**不会**上传到任何云端 |

⚠️ 一个必须知道的前提：**服务在跑的时候电脑不能休眠**。Windows 默认一段时间后睡眠，睡眠后手机就连不上了。见第 6 节。

## 1. 三步上线

### 第 1 步：生产构建

```bash
npm run build
```

这一步会输出 40 多个路由的打包结果，耗时 1–3 分钟。**只有改过代码才需要重新构建**，日常重启不用。

> 为什么不能用 `npm run dev` 长期对外：
> 开发服务器按需编译、单线程，手机上第一次点开一个页面要等好几秒；它还会暴露调试信息。
> 自己的电脑上用 dev 无所谓，给别人/手机用必须用生产构建。

### 第 2 步：放行防火墙（只需做一次）

右键「开始」→ **Windows PowerShell（管理员）** → 执行：

```powershell
cd D:\project\2026-10-17-00-16-15
powershell -ExecutionPolicy Bypass -File scripts\open-firewall.ps1
```

脚本只对 **专用网络（Private）** 放行 TCP 3100 —— 也就是说你在咖啡店连公共 Wi-Fi 时，即使服务开着，别人也连不进来。

不想用脚本的话，图形界面操作是：
`控制面板 → 系统和安全 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 3100 → 允许连接 → 只勾「专用」`

### 第 3 步：启动

**方式 A（推荐，双击即可）**：双击 `start-lan.bat`
没有构建产物时它会自动先构建；启动后窗口会一直开着，关掉窗口服务就停了。

**方式 B（命令行）**：

```bash
npm run lan
```

启动成功的输出长这样：

```
  AI 高中学习教练 · 局域网服务
  ────────────────────────────────────────────
  监听地址   http://0.0.0.0:3100
  本机访问   http://localhost:3100
  手机访问   http://192.168.1.6:3100   (WLAN)
  Cookie 安全标记   不加密（HTTP 可正常登录）
  ────────────────────────────────────────────
```

`0.0.0.0` 表示"监听所有网卡"，这正是手机能连进来的原因；`localhost` 只有本机能访问。

## 2. 手机怎么用

1. 确认手机和电脑连的是**同一个 Wi-Fi**（手机没开流量、没连访客网络）。
2. 手机浏览器输入启动时打印的「手机访问」地址，例如 `http://192.168.1.6:3100`。
3. 用之前建的账号登录（**不要用演示账号**，见第 5 节）。

### 添加到主屏幕（强烈建议）

加完之后从桌面图标进入，全屏无地址栏，和装了 App 一样：

- **iPhone（Safari）**：分享按钮 → 「添加到主屏幕」
- **Android（Chrome / Edge）**：右上角 ⋮ → 「添加到主屏幕」/「安装应用」

图标与启动页已经配好了（`app/manifest.ts` + `src/app/icon.png`），不需要额外操作。

### 手机上用起来和电脑有什么区别

界面针对手机做了专门处理：

- 底部有 5 个 Tab（首页 / 答疑 / 错题本 / 计划 / 报告），单手就能切换
- 输入框字号固定 16px，iOS 聚焦时不会把页面放大
- 拍照上传题目的按钮在手机上会直接调起相机
- 手机照片普遍 3–12 MB，上传前会在浏览器里自动压到长边 1600px（通常 200–500 KB），
  识别精度基本不受影响，上传快很多
- 底栏留出了 iPhone 底部指示条的安全区，不会被挡住

## 3. 让服务常驻（可选）

### 3.1 关掉自动睡眠

**这是最容易忽略、后果最明显的一步**：电脑一睡，手机就白屏。

`设置 → 系统 → 电源和电池 → 屏幕和睡眠`：
- 「接通电源时，使设备进入睡眠状态」→ **从不**
- 「接通电源时，关闭屏幕」→ 可以保留（关屏不影响服务）

笔记本合盖也要注意：`控制面板 → 电源选项 → 选择关闭盖子的功能 → 接通电源时：不采取任何操作`。

### 3.2 开机自动启动

用「任务计划程序」：

1. Win + R 输入 `taskschd.msc`
2. 右侧「创建任务」
3. **常规**：名称填 `AI 学习教练`，勾选「不管用户是否登录都要运行」需要存密码；
   只想登录后启动就选「只在用户登录时运行」，并勾「使用最高权限运行」
4. **触发器**：新建 → 「登录时」（或「启动时」）
5. **操作**：新建 → 程序或脚本填
   ```
   D:\project\2026-10-17-00-16-15\start-lan-hidden.bat
   ```
   （用 `-hidden` 这个版本：它不会停在 pause 上，日志写到 `.data\server.log`）
6. **条件**：取消勾选「只有在计算机使用交流电源时才启动此任务」（笔记本用电池时也能跑）

之后每次开机自动起服务。查日志：

```bash
tail -50 .data/server.log
```

## 4. 从外网访问（不在同一个 Wi-Fi）

这和"局域网访问"是完全不同的问题，见专门的 **[docs/REMOTE_ACCESS.md](REMOTE_ACCESS.md)**。

一句话版本：

| 方案 | 安全性 | 难度 | 建议 |
|---|---|---|---|
| **Tailscale** | 高：设备间加密 + 身份认证，不对公网开放任何端口 | 低：两端装客户端、同一账号登录 | ✅ 首选 |
| **IPv6 直连** | 中：明文，公网可扫到端口 | 中：路由器放行 + 前缀会变 | 你的宽带已有公网 IPv6，可作备选 |
| Cloudflare Tunnel | 高：TLS + 访问控制 | 中：需要域名 | ✅ 有域名就选它 |
| 路由器端口转发 | **低** | 中 | ❌ 不建议 |

⚠️ **绝对不要把 3100 端口直接映射到公网**。这个应用目前是「单机自用」定位：
会话是签名 Cookie、限流是进​​程内的、没有多因素认证、演示账号还带公开密码。
在没有 HTTPS、没有访问控制的情况下暴露到公网，等于把学生的全部学习记录公开。

## 5. 上线前的安全清单（照着勾）

| 检查项 | 怎么做 |
|---|---|
| **删掉或改密码演示账号** | 演示账号 `demo@study.local` 的密码写在 README 里，是公开的。在「设置」页改密，或直接删掉这个用户 |
| **关闭自助注册** | `.env` 里改 `ALLOW_SELF_SIGNUP=false`，重启服务。否则同一 Wi-Fi 下任何人都能注册 |
| **确认 Cookie 策略** | 用 http 访问时 `COOKIE_SECURE` 必须是 `auto` 或 `false`。设成 `true` 会表现为「登录成功但刷新又回登录页」 |
| **改 `SESSION_SECRET`** | 至少 32 位随机串。泄露意味着别人可以伪造任意用户的会话 |
| **别在公共 Wi-Fi 上开** | HTTP 是明文传输，同网络下有技术能力的人可以抓包。家庭/宿舍网络可接受 |
| **定期备份** | `npm run backup`，见第 7 节 |
| **AI Key 不要外传** | 它只在服务端 `.env` 里，绝不会下发到浏览器；但代码仓库、截图、聊天里都不要出现 |

`npm run lan` 每次启动都会自动检查前四项，有问题会直接拒绝启动并说明原因。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 手机上「无法访问此网站」 | ① 不在同一 Wi-Fi；② 防火墙没放行（第 1 步第 2 节）；③ 电脑睡眠了；④ 路由器开了「AP 隔离」，改成允许设备互访 |
| 电脑上 `localhost:3100` 能开，手机不行 | 说明服务只监听了 127.0.0.1。用 `npm run lan`（不要用 `npm start`），它是 `-H 0.0.0.0` |
| 登录后一刷新又回到登录页 | `COOKIE_SECURE` 配错了，用 http 访问时不能是 `true`。见第 5 节 |
| 上传题目图片提示「格式不支持」 | iPhone 的 HEIC。正常选图会自动转 JPEG；若浏览器解不开，把 `设置 → 相机 → 格式` 改成「兼容性最佳」，或在相册里先截图 |
| 点「开始识别」一直转圈 | 视觉模型识别一道题通常 8–20 秒，题目复杂时更久。超过 1 分钟无响应看 `.data/server.log` |
| 服务启动就报 `EPERM` / 删不掉 `.next` | 本项目所在环境有文件删除保护。**不要移动 `.next` 目录**，原地构建即可 |
| 改了代码但手机上看不到变化 | 生产模式不会热更新。重新 `npm run build`，然后重启服务 |
| 端口 3100 被占用 | 换端口：`set PORT=3101 && npm run lan`，或找出占用进程 `netstat -ano \| findstr :3100` |

## 7. 备份与恢复

```bash
npm run backup
```

会复制到 `.data/backups/2026-10-18-101530/`：
- `dev.db` —— 账号、错题、作答、掌握度、计划
- `uploads/` —— 题目原图

**恢复**：停止服务 → 把备份里的 `dev.db` 与 `uploads/` 覆盖回 `.data/` → 重新启动。

> 建议在停服务时备份（SQLite 写入过程中复制可能拿到不一致的副本）。
> 备份不要放进网盘共享目录 —— 里面有学生全部学习记录。

如果换电脑：把整个项目目录（至少 `src`、`prisma`、`.data`、`.env`、`package.json`）拷过去，
`npm install` → `npm run build` → `npm run lan` 即可。

## 8. 更新代码后的标准动作

```bash
npm run build      # 重新打包（必做）
# 停掉正在跑的服务（Ctrl+C 或关掉窗口）
npm run lan         # 重新启动
```

数据库结构没变的话不用迁移。如果拉到了带新 `prisma/migrations/` 的版本：

```bash
npm run db:deploy   # 只应用已存在的迁移，不会重建数据库
```

## 9. 这套方案的边界

说清楚能力范围，避免误判：

- **单机单用户为主**：同时 2–3 台设备用没问题（SQLite 读并发足够），但不是为几十人设计的
- **限流是进程内的**：一台机器一个进程，够用；要做多实例得换共享存储
- **没有 HTTPS**：局域网内部可接受；走 Tailscale 由它负责加密；真要公网必须自己加 TLS
- **依赖 Windows 不休眠**：这是"用电脑当服务器"的固有代价，长期跑建议用旧笔记本或迷你主机专职跑
